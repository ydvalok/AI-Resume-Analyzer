# AI Resume Analyzer

An AI-powered web app that compares a resume with a job description and provides a match score, matching skills, missing skills, strengths, and improvement suggestions.

## Features

- User signup and login
- JWT authentication
- PDF resume upload
- AI-powered resume analysis
- Match score and skill gap analysis
- Analysis history
- Delete previous analyses

## Tech Stack

- React
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Gemini AI
- CSS
